# STUDI-_KASUS_-4_Soraya-Ghina_081
Program ini digunakan untuk mengelola data buku menggunakan dictionary. Data awal yang disimpan yaitu judul buku, penulis, dan tahun terbit.

Program menggunakan while True agar menu dapat ditampilkan berulang kali. Pengguna dapat memilih beberapa menu, yaitu menampilkan data buku, menambahkan penerbit, mengubah nama penulis, dan menghapus penerbit. 

Pada menu tampil data digunakan for untuk menampilkan isi dictionary.

Menu tambah penerbit digunakan untuk memasukkan data penerbit, sedangkan menu ubah penulis digunakan untuk mengganti nama penulis.

Pada menu hapus penerbit terdapat if untuk mengecek data penerbit sebelum dihapus menggunakan del. Jika pengguna memilih menu 5, break digunakan untuk menghentikan program. 

Setelah keluar, program menampilkan kembali data buku yang sudah diperbarui.
